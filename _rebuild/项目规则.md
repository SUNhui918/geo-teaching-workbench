# 项目规则.md

每次更新工作台时，必须遵守以下四条（自动执行，无需用户提醒）：

1. **更新日志**：每次修改（新增工具、修复问题、调整功能），都要在 lib/changelog.js 的最前面添加一条更新记录：日期用当天日期，内容用一句老师能看懂的话说明改了什么，涉及具体工具的要把工具名称（与首页卡片标题完全一致）填进 tools。纯粹的代码整理、不影响使用的改动不用记录。
   - tools 里出现的工具，首页卡片右上角会自动显示红色「新」角标（最近 30 天内有效）。

2. **新工具页面配工具条**：每次新增自制 HTML 工具页面（dist/ 根目录），都要在该页面 </body> 前加：
   `<script src="lib/workbench-bar.js"></script>`
   （gushengwutupu / yanshitupu 子文件夹里的页面写 `../lib/workbench-bar.js`）。
   该脚本会在页面右下角自动生成悬浮工具条：🧭 收起标签，展开后有「返回工作台」「全屏」按钮和站点名小字；会自动避让页面右下角已有的浮动元素。首页 index.html、卫星地图.html、图谱编号小页面（001.html 等）不加。

3. **个人信息（2026-11-10 起）**：工作台中一律不得出现任何个人姓名、学校名称、教研组等个人信息；新增页面不注入署名，也不加源码署名注释。教学需要保留的真实地名（如常州「横山桥」）与第三方资料来源署名不受影响。

4. **缓存版本号**：离线缓存（sw.js）对 lib/ 里的脚本、图片等静态文件是「有缓存就不再下载」。所以每次修改 lib/ 里的任何文件（包括 changelog.js、relations.js、workbench-bar.js），或修改页面引用的图片、脚本等非 HTML 文件，都要把 sw.js 第一行附近的 `const CACHE = 'geo-workbench-vN'` 中的数字 +1，否则用过工作台的设备会一直显示旧内容（如「新」角标不更新）。只改 HTML 页面不需要改版本号。
   - 新页面需要的第三方库（three.js、d3、echarts 地图等）一律先引用仓库里的本地文件，外网 CDN 只作为备用，保证断网能用。
