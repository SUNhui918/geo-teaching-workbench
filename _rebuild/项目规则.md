# 项目规则.md

每次更新工作台时，必须遵守以下三条（自动执行，无需用户提醒）：

1. **更新日志**：每次修改（新增工具、修复问题、调整功能），都要在 lib/changelog.js 的最前面添加一条更新记录：日期用当天日期，内容用一句老师能看懂的话说明改了什么，涉及具体工具的要把工具名称（与首页卡片标题完全一致）填进 tools。纯粹的代码整理、不影响使用的改动不用记录。
   - tools 里出现的工具，首页卡片右上角会自动显示红色「新」角标（最近 30 天内有效）。

2. **新工具页面配工具条**：每次新增自制 HTML 工具页面（dist/ 根目录），都要在该页面 </body> 前加：
   `<script src="lib/workbench-bar.js"></script>`
   （gushengwutupu / yanshitupu 子文件夹里的页面写 `../lib/workbench-bar.js`）。
   该脚本会在页面右下角自动生成悬浮工具条：🧭 收起标签，展开后有「返回工作台」「全屏」按钮和署名小字；会自动避让页面右下角已有的署名元素。首页 index.html、卫星地图.html、图谱编号小页面（001.html 等）不加。

3. **署名**：新增自制页面一律注入署名——源码注释（`<!-- 本页面由横山桥高级中学 孙慧制作，仅供教学使用，未经许可不得商用 -->`）+ 右下角可见署名 div「横山桥高级中学 孙慧制作」。
